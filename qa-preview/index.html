What was fixed

  • Bounded provider body reads, cache reads/writes and rate-limiter calls. A stalled cancellation cannot lock the media-download queue.
  • Queued downloads cancel promptly without allowing later downloads to overtake the active one.
  • Coalesced searches keep running for other subscribers when one caller cancels.
  • Audio queue/flush waits, clip playback startup, and editor image/audio decoding now have deadlines and cleanup.
  • Quick Batch refuses an undecodable photo rather than showing a false “Ready”.
  • Explicit frame durations preserve the final frame: the exported duration is 15.00 seconds, not 14.97.

Verification scope

Both MP4s were reopened in Chromium, played and seeked. Changing pixels were verified inside both clip windows. FFmpeg independently decoded all 450 frames in each file without errors. Eight planner calls each received the entire script; provider search requests kept per_page=3.
